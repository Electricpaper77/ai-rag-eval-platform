# AgentTrust IQ Repository Manifest

This file is the quick-start contract for reviewers and coding agents.

## Project Identity

AgentTrust IQ is a model-agnostic AI agent reliability and evaluation platform that tests groundedness, citation support, prompt-injection resistance, PII handling, unsafe tool actions, latency, and auditability before release.

Gemini is supported only as an optional evaluator integration. The deterministic baseline requires no external model or API key.

## Architecture


## Do-Not-Break Rules

- Do not change evaluator behavior or the deterministic score/check contract for documentation work.
- Do not present controlled fixtures as customer-production telemetry or independent benchmarks.
- Do not introduce aggregate recruiter metrics from a source other than `hiring_eval_summary.json`.
- Do not imply that Gemini is required; it is optional.
- Do not claim vendor integrations that are not implemented in the repository.
- Do not remove JSONL audit evidence references or weaken the evidence qualifications.
- Do not add dependencies or visual redesigns for credibility edits.

```text
Positioning -> Canonical controlled metrics -> Deterministic demo fixture -> JSONL evidence -> Focused tests
```
