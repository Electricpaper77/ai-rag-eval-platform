# Project Summary

AgentTrust IQ is a model-agnostic AI agent reliability and evaluation platform that tests groundedness, citation support, prompt-injection resistance, PII handling, unsafe tool actions, latency, and auditability before release.

## Strongest Proof

- Deterministic FastAPI evaluation with explicit release, block, or escalate decisions.
- Replayable JSONL evidence and focused artifact-contract tests.
- Canonical six-case controlled summary in `docs/artifacts/eval_runs/hiring_eval_summary.json`.
- Optional Gemini evaluator integration; no external model is required for the baseline.
- Prometheus metrics and deployment packaging for Docker, Kubernetes, Helm, and Terraform.

## Evidence Boundary

Canonical source: `docs/artifacts/eval_runs/hiring_eval_summary.json`, generated by `app.eval_harness.run_eval_harness` from the checked-in JSONL cases. Sample size: **6 deterministic fixture cases**. The **0.159 ms** value is local deterministic evaluator runtime, not LLM, API, RAG, or end-to-end latency. Canonical metrics are controlled demo/test results, not customer-production telemetry. The pytest suite was not executed in this environment. GPU workloads are simulated by default, no live production Kubernetes cluster is claimed, and packaging files do not prove an active deployment.
