# Interview Talk Track

## 60-Second Explanation

AgentTrust IQ is a model-agnostic AI agent reliability and evaluation platform that tests groundedness, citation support, prompt-injection resistance, PII handling, unsafe tool actions, latency, and auditability before release. It turns those checks into a release, block, or escalate decision and records replayable JSONL evidence. The deterministic baseline requires no model API; Gemini is an optional evaluator integration.

## Technical Deep Dive

**How is the platform structured?**
The FastAPI service exposes evaluation and OpenAI-compatible inference surfaces. Reliability checks, routing, metrics, and JSONL artifacts are first-class outputs.

**How do you avoid flaky model-dependent tests?**
The baseline evaluator and focused demo are deterministic. Optional Gemini evaluation is never required for the reproducible test path.

**How are unsafe tool actions handled?**
The demo classifies read-only actions separately from destructive or irreversible actions and sends the latter to a human-approval gate.

**How do you prove the metrics?**
Open the canonical summary, inspect its six underlying JSONL case rows, and run `tests/test_eval_harness.py`. The separate demo score of 92 is a fixed fixture result asserted by `tests/test_agenttrust_demo.py`, not an aggregate metric.
