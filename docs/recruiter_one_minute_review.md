# Recruiter One-Minute Review

AgentTrust IQ is a model-agnostic AI agent reliability and evaluation platform that tests groundedness, citation support, prompt-injection resistance, PII handling, unsafe tool actions, latency, and auditability before release.

## Strongest Hiring Signals

- Deterministic evaluation with explicit release, block, or escalate decisions.
- Replayable JSONL evidence for groundedness, citations, injection resistance, PII handling, and unsafe requests.
- FastAPI and OpenAI-compatible interfaces with Prometheus-format metrics.
- Gemini available only as an optional evaluator integration.
- Deployment packaging without a claim of a live production cluster.
