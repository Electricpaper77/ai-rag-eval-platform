# AgentTrust IQ Proof Guide

AgentTrust IQ is a model-agnostic AI agent reliability and evaluation platform that tests groundedness, citation support, prompt-injection resistance, PII handling, unsafe tool actions, latency, and auditability before release.

## Evidence Boundary

- The Vercel page is a static walkthrough; the FastAPI service runs locally.
- The deterministic baseline requires no model API.
- Gemini is an optional evaluator integration enabled only when `GEMINI_API_KEY` is configured.
- All recruiter-facing aggregate metrics below come from one canonical source: `docs/artifacts/eval_runs/hiring_eval_summary.json`.
- Metrics are controlled demo/test results, not customer-production telemetry, independent model benchmarks, or production capacity claims.

## Reproduce the Proof

```bash
python -m pytest tests/test_agenttrust_demo.py -q
python -m pytest tests/test_eval_harness.py -q
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

Then request:

```bash
curl -s http://127.0.0.1:8000/demo/agenttrust-iq
```
