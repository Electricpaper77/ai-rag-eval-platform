# AgentTrust IQ Reviewer Packet

AgentTrust IQ is a model-agnostic AI agent reliability and evaluation platform that tests groundedness, citation support, prompt-injection resistance, PII handling, unsafe tool actions, latency, and auditability before release.

## Architecture

```text
Prompt + Agent Output + Evidence + Proposed Tool Action
  -> AgentTrust IQ Reliability Evaluation
  -> Release / Block / Escalate
  -> JSONL Audit Evidence
```

## Optional Gemini Integration

The deterministic evaluator is the baseline. Gemini-assisted evaluation is optional and runs only when `GEMINI_API_KEY` is configured; the platform remains usable and testable without it.

## Short Pitch

AgentTrust IQ makes agent-release decisions inspectable: it checks evidence support, injection and privacy risks, unsafe tool actions, latency, and audit completeness, then records a release, block, or escalate decision in JSONL.
