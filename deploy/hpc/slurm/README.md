# Isolated Slurm proof

Gate 6 uses the host Linux runner's packaged Slurm binaries with an
unprivileged, single-node configuration generated by
`scripts/gate6_slurm_smoke.sh`.  It proves controller startup, compute-node
registration, `srun hostname`, a scripted batch job, and captured accounting.

This is a scheduler smoke test only.  It does not prove multi-node HPC scale,
GPU execution, or production Slurm operations.  GPU requests are mapped
separately by `gpu_platform.scheduler_mapping`; there is no live integration
between Kubernetes and Slurm.
